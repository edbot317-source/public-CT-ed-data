## Caveats and Decisions

- The six verified clean-panel datasets were copied from the source repo's committed `clean-data/` outputs, then regenerated with their `build.py` scripts and compared to the source panels; all matched.
- Some original clean scripts rely on other cleaned panels for lookup fields such as district codes. Those verified dependency CSVs are copied under `raw/_dependencies/` for the affected dataset so the public build remains self-contained.
- SAT, graduation, SWD outplacement, and archived total-expenditure raw folders retain source HTML or XLSX files where those were the scraped source artifacts; cookie jars and screenshots are excluded.
- `special_education_expenditures` is released as a long district-year-category file. Archived wide categories and current long line items are harmonized only to common identifier/value fields; category labels remain as reported by EdSight.
- The four ECS datasets (added 2026-09-14, rebuilt 2026-09-15) are town-grain. Amounts are CSDE's official entitlement files. Formula inputs are parsed from the official OFA/CSDE per-town calculation shells (FY2019-FY2021, FY2023-FY2027; received from the state by email, not downloadable, stored with SHA-256 hashes in `raw/ofa/_provenance.tsv`) and from the School and State Finance Project's copy of the FY2022 shell; SSFP's other copies are parsed as cross-checks and agree to the cent. Validation, including the rebuild test against CSDE's published grants for every year FY2019-FY2027, is in `data/town_year_ecs_inputs/VALIDATION.md`; `ecs_rebuild_by_town_year.csv` beside it lists every town-year's rebuilt grant. The FY2027 inputs await CSDE's final calculation; the SSFP model workbook is fetched from a Dropbox link that rotates, so the download log records the file hash.
- `seda_k_grade_subject` and `town_grade_subject_seda_baseline` (added 2026-09-14) are derived from SEDA 2025.2; `k` is computed from the NAEP parameters in the SEDA documentation (Table 9), and the regression cross-check columns come from the national long files, which are not redistributed (about 119 MB each) -- the per-year slopes are kept in `raw/k_gcs_on_cs_by_year.csv` so `build.py` reproduces the panel.
- `tools/ecs_formula_explorer/` is code and built output, not a dataset: the ECS Formula Explorer page (FY2019-FY2027 from 2026-09-15), its data build, the test-score simulation module with unit tests, and logged simulation runs (including PNG figures, exempted from the `*.png` ignore rule).
